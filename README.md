# Sri Sri Maa Durga Puja Committee — Jugsalai Fatak

A static website designed for GitHub Pages. No paid hosting or build tools are needed.

## Files
- `index.html` — website content
- `style.css` — red, black and gold responsive design
- `script.js` — mobile navigation and copy UPI button
- `assets/maa-durga.jpg` — supplied Maa Durga photo
- `assets/donation-qr.jpg` — supplied donation QR
- `assets/committee-schedule-reference.jpg` — original schedule/member poster for reference

## Publish free on GitHub Pages (mobile)
1. Open GitHub in your browser and create a new **public** repository, for example `durga-puja-committee`.
2. Open the repository and choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder with its three images. Keep the filenames and folder structure unchanged.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
6. Wait a few minutes. GitHub will show your free website URL in Settings → Pages.

## Before publishing
- Verify the puja schedule and every member's spelling with the committee.
- Confirm the donation QR and UPI receiver details with a trusted UPI app before sharing the site publicly.
- This site uses a Google Fonts import; the rest of the website works without it if the font service is unavailable.
